# JFS-12 – Recruitment & Applicant Tracking

## Project Description

A Recruitment & Applicant Tracking System where companies can post jobs, candidates can apply with resumes, and recruiters can manage applicants through the interview and hiring process.

## Roles

- Admin
- Recruiter
- Interviewer
- Candidate

## Functional Requirements

### FR1 – Create, Publish and Close Jobs

**User Story:**  
As a Recruiter, I want to create, publish, and close job postings so that I can manage open positions and stop accepting applications when hiring is complete.

**Story Points:** 3

**Acceptance Criteria:**
- Recruiter can create a job.
- Recruiter can enter job title, description, skills, and experience.
- Recruiter can publish a job.
- Published jobs are visible to candidates.
- Recruiter can close a job.
- Candidates cannot apply to a closed job.

### FR2 – Search Jobs and Apply Once

**User Story:**  
As a Candidate, I want to search available jobs and apply to a job once so that I can find suitable opportunities and avoid submitting duplicate applications.

**Story Points:** 5

### FR3 – Move Applications Across Stages

**User Story:**  
As a Recruiter, I want to move candidates between application stages so that I can track their progress through the hiring process.

**Story Points:** 5

### FR4 – Schedule Interviews Without Clashes

**User Story:**  
As a Recruiter, I want to schedule interviews without interviewer time conflicts so that interviews can be arranged efficiently.

**Story Points:** 8

### FR5 – Submit Interview Scorecard

**User Story:**  
As an Interviewer, I want to submit an interview scorecard so that the Recruiter can evaluate the candidate based on my feedback.

**Story Points:** 3

### FR6 – Generate Offer Letter

**User Story:**  
As a Recruiter, I want to generate an offer letter for a selected candidate so that I can formally offer the candidate the job.

**Story Points:** 5

### FR7 – Track Application Status

**User Story:**  
As a Candidate, I want to track the status of my job application so that I can know the current stage of my application in the hiring process.

**Story Points:** 3

### FR8 – View Hiring Funnel Analytics

**User Story:**  
As an Admin, I want to view hiring funnel conversion for each job so that I can understand how candidates progress through the recruitment process.

**Story Points:** 5
